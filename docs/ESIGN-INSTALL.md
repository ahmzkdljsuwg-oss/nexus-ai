# تثبيت NEXUS AI عبر ESign

## ما الذي ستستخدمه

- `NEXUS-AI.ipa` — نسخة Release مترجمة (arm64).
- شهادة توقيع iOS صالحة مع Provisioning Profile يسمح بـ `ai.nexus.app`.
- تطبيق ESign على iPhone.

> الملف الحالي غير موقّع. ESign لا يثبّت ملفاً بدون إعادة توقيع. لا توجد شهادة Apple في المشروع، ولا يمكن إنشاء توقيع صالح بدون شهادة تخصك.

## متطلبات الشهادة والملف التعريفي

- الشهادة: ملف `.p12` صالح مع المفتاح الخاص وكلمة المرور.
- الملف التعريفي: `.mobileprovision` صالح وغير منتهٍ، ويسمح بـ `ai.nexus.app`.
- يجب أن يبقى **Bundle ID** داخل ESign هو `ai.nexus.app`؛ لا تغيّره.
- في توقيع Ad Hoc: أضف UDID جهاز iPhone إلى الحساب، ثم أعد إنشاء البروفايل بعد الإضافة.
- شهادة Enterprise/In-House قد تعمل داخل ESign فقط ولا تصلح لـ GitHub Actions؛
  الـ workflow يتطلب `Apple Distribution` أو `Apple Development` مع بروفايل مطابق.
- لا تضف `.p12` أو `.mobileprovision` إلى المستودع أو إلى GitHub Secrets إلا إذا
  أردت تشغيل البناء الموقّع من GitHub Actions.

## خطوات ESign

1. انقل `NEXUS-AI.ipa` إلى تطبيق Files على iPhone (AirDrop أو iCloud Drive أو تنزيل مباشر).
2. افتح ESign، ثم **ملفاتي / Files**، واختر ملف IPA.
3. اضغط على الملف واختر **توقيع / Sign**.
4. اختر الشهادة وProvisioning Profile الصالحين.
5. تحقق من **Bundle ID**: يجب أن يبقى `ai.nexus.app` ويطابق البروفايل. لا تغيّره.
6. اترك خيارات entitlements الافتراضية إلا إذا كانت شهادتك تتطلب إضافات.
7. اضغط **توقيع** وانتظر انتهاء العملية.
8. اضغط **تثبيت / Install**.
9. بعد التثبيت، إذا ظهرت رسالة مطوّر غير موثوق: **الإعدادات → عام → VPN وإدارة الجهاز → اسم المطوّر → الثقة**.
10. افتح NEXUS AI، ثم **الإعدادات**، وأدخل رابط Backend الإنتاجي (مثال الصيغة `https://<service>.up.railway.app`)، واضغط حفظ ثم فحص الاتصال.

## ملاحظات مهمة

- لا يوجد عنوان Backend افتراضي داخل التطبيق. لن تظهر حالة ONLINE قبل إدخال رابط صحيح والتحقق منه فعلياً.
- لا تضع `GEMINI_API_KEY` أو `MISTRAL_API_KEY` أو `DATABASE_URL` في التطبيق. كلها تبقى في Railway Variables.
- إذا انتهت صلاحية الشهادة أو أُلغيت، سيتوقف التطبيق عن العمل عند إعادة التثبيت. استخدم شهادة تخصك.
- ESign أداة خارجية؛ لم يتم اختبار التثبيت على جهاز iPhone من مساحة العمل. ما تم التحقق منه هو سلامة حزمة IPA وبنيتها ومعماريتها وتطابق معرف الحزمة.
- لإعادة إنتاج الملف: `docs/IPA-BUILD-REPORT.md` أو شغّل Workflow من GitHub Actions.
