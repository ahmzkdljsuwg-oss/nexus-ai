# تقرير الإصلاح — Premium Splash + Design + Automatic URL

التاريخ: 2026-11-15
الفرع: `lemon/nexus-premium-splash`

## 1. ما تم إصلاحه فعلياً

### شاشة التحميل
- أُضيفت شاشة تحميل حقيقية داخل تطبيق Expo: `mobile/src/screens/SplashScreen.js`.
- تعتمد على تصميم `NEXUS AI — v2 Premium.html`: شعار ذهبي دائري، توهج، `NEXUS AI`، `نظام ذكاء التداول`، `ADVANCED MARKET INTELLIGENCE`، شريط تقدم وحالة خادم.
- تظهر عند أول تشغيل فوق الواجهة الرئيسية، ولا تُتجاوز فوراً: الحد الأدنى 2.2 ثانية، والحد الأقصى 6.5 ثانية.
- الانتقال إلى الواجهة يتم بتلاشي 420ms بعد اكتمال التهيئة أو انتهاء المهلة.
- حالة الخادم في شاشة التحميل صادقة: لا تعرض `SERVER VERIFIED` إلا عند اتصال فعلي، وتعرض `AWAITING SERVER DEPLOYMENT — OPENING OFFLINE` عند غياب الرابط.

### التصميم
- طُبّقت ألوان التصميم المعتمد في `mobile/src/theme/colors.js` (`#070711`, `#111120`, `#F0A500`, `#FFB930`, `#00C896`, `#FF3D5A`).
- أُضيف `PremiumBackdrop` إلى كل الشاشات (توهج ذهبي/أزرق كما في HTML).
- الرئيسية: شعار ذهبي، شريط `INTELLIGENCE`، أزرار تحديث وإعدادات، تاريخ اليوم، بطاقة Hero ذهبية، وبطاقة `AWAITING SERVER DEPLOYMENT` بدلاً من مطالبة إجبارية برابط.
- بطاقات الأسواق، شريط التبويبات، شاشة الإعدادات حصلت على نفس اللغة البصرية.
- التصميم الأصلي ForexBro والملاحة الحالية محفوظان، ولم تُحذف أي شاشة أو وظيفة.

### BASE_URL
- `pickBaseUrl` يفضّل رابط الإنتاج المضمّن في البناء، ثم الرابط المحفوظ كاحتياط، وإلا يبقى فارغاً بصدق.
- لا يطلب التطبيق الرابط عند التشغيل، ويفتح الرئيسية حتى بدون خادم.
- الإعدادات تعرض حالة رابط الإنتاج، وإدخال الرابط أصبح في قسم `OPTIONAL FALLBACK URL` فقط.
- زر `AUTO` يعيد استخدام رابط الإنتاج المضمّن.

### لم يتغير
- الأسواق السبعة منفصلة.
- تحليل عادي وتحليل قوي لم يُعدّلا.
- لا تسجيل دخول، ولم تتم إضافته.
- لا أسعار وهمية، ولا حالة Online وهمية.

## 3. المتبقي والسبب

الرابط الإنتاجي غير موجود بعد. `app.json` يحتوي `extra.apiBaseUrl: ""`، والمتغير `EXPO_PUBLIC_API_BASE_URL` غير مضبوط. لذلك يعمل التطبيق بوضع `AWAITING SERVER DEPLOYMENT`، وهذا سلوك صادق وليس خطأ.

لتفعيل الاتصال التلقائي:
1. انشر `backend/` على Railway.
2. أضف متغير المستودع `NEXUS_API_BASE_URL` بقيمة رابط Railway الفعلي (HTTPS).
3. أعد بناء التطبيق، فيُضمّن الرابط تلقائياً ويُستخدم دون إدخال يدوي.
